WYSIWYG math

The page is the worksheet

No code cells, no formula bar, no separate sheet. An equation typed with the equation editor is typeset like any other, and it is the calculation. Strix reads the calculated equations in reading order and keeps every result current, waiting until the caret leaves an equation so nothing changes under your typing.

  • One = for everything: a definition, a result to show (in the unit you ask for), an equation to solve for its one unknown, or a check with ✓/✗.
  • Solving: symbolic isolation when the unknown appears once, numeric roots otherwise.
  • Units are upright and coloured, kept through results, converted to the unit you last wrote for that kind; dimension errors are caught.
  • Solution steps: the formula, the values substituted, the result, aligned at =.
  • Number format: digits, decimals or significant figures, trailing zeros, scientific notation.
Features

A calculation notebook that is also a real document

What is in Strix today. Planned work is marked as planned.

01 · Live calculations

Results that never go stale

Every calculated equation and table is re-evaluated after each edit, on F9 and when the file opens. An error shows ⚠ and its message; the rest of the sheet still calculates.

02 · Solving and checks

Write the relation, get the unknown

F = m·a with F and m known gives a. Comparisons ≤ ≥ < > ≠ verify limits with ✓ or ✗. Sums, products, ranges and vectors included.

03 · Units

Quantities, not numbers

SI and engineering units with prefixes, dimensionless units kept, working units, case hints ("did you mean kN?").

04 · Exercises

Worked problems with structure

Statement, data, nested questions, a solution under each question and one results summary, in a locked layout.

05 · CAD

Drawings tied to the numbers

Coordinates are expressions of parameters; dimensions show their values; change L and the drawing follows.

06 · Word-like editing

The report around the maths

Ribbon interface, styles, lists, tables, references, comments, track changes, spelling, 27 interface languages.

07 · Files and exports

Live files, static copies

Saves .xmath / .xmathm; opens DOCX, DOC, ODT, RTF, HTML, Markdown, LaTeX; exports PDF, PNG, LaTeX, HTML, Markdown.

08 · Agent control

Every action is a command

One command registry behind the ribbon, shortcuts, the CLI, a control channel and an MCP server.

09 · Cross-platform and web

Native everywhere, and in the browser

Windows, macOS, Linux and BSD as native apps, and the same app compiled to WebAssembly for the web. Pure Rust, no panics by design: no unwrap or unsafe in production code.

Exercises

Problems with a structure you can't break

Math › Exercise inserts a worked problem held together by locked parts: you write freely inside them, but the skeleton stays.

  • Statement, data and questions, lettered and nested to three levels (a), a.1), a.1.1)), with notes between them.
  • The solution repeats each question as a read-only line, with its working under it; the working follows its question when the questions change.
  • A sandbox: what an exercise defines stays inside it, so two exercises can both use L.
  • Data and variants A, B, C… in the Exercise Properties pane; picking a variant recalculates everything.
  • One results summary at the end of the document lists every marked result with its value.
CAD drawings

Drawings driven by the calculations

A CAD drawing sits in the text like a picture, but its coordinates can be expressions of the parameters defined above it. Change L = 4.5m and the beam redraws; its dimension reads the new value.

  • Labels from parameters: {{L}} shows 4.5m, {{L:both}} shows L = 4.5m, <> the measured size.
  • An editor on the drawing's sheet: lines, circles, arcs, polylines, rectangles, texts and dimensions, with an AutoCAD-style command line (@dx,dy, @d<a).
  • Exact snaps on the true curves (endpoint, midpoint, centre, intersection, perpendicular, tangent…) from a geometry kernel tested to 1e-9.
  • Grips reshape objects and keep the expressions: L becomes L + 0.5.
  • Selection as in AutoCAD: click adds, Shift+click removes, windows, crossings, lassos, fences; a right-click menu for what is under way.
  • A Properties pane: layer, colour, lineweight, linetype, and the geometry as numbers or expressions; layers managed beside the sheet.
  • Saved as JSON with an automatic SVG picture, so other programs still show it.
Agent control

Built to be driven by people and by agents

Everything Strix does is a command with an id and parameters. The ribbon, keyboard shortcuts, command search, the command line, a local control channel and the MCP server all run the same commands, and programmatic calls never open dialogs.

Get started

Build it and open the sample

Strix is in alpha. Installers are on the Releases page (Code signing policy). To build it yourself you need a Rust toolchain (1.95 or later); the web build also needs Trunk and the wasm32-unknown-unknown target.

  1. Clone

    git clone https://github.com/nabre/strix
cd strix

  2. Run the desktop app

    cargo run --release -p strix -- --sample
cargo run --release -p strix -- problem.xmath

  3. Or run it in the browser

    cd apps/strix-web
trunk serve
# open http://127.0.0.1:8771/?sample

Then open the Math tab: New Calculation, type L = 4.5 m, and keep going. Design notes: calculations, exercises, CAD.
